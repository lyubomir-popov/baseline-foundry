# Quickstart: Hero divider and quiet linked titles

1. Build and serve the BF demo.
2. Open `/demo/components/basic-section.html`; inspect the linked title at rest, visited, hover and keyboard focus in every tier.
3. Open `/demo/components/hero.html`; inspect a default hero and the borderless specimen at 360×844 and 1280×900.
4. Verify the closing-media specimen retains its shallow lead and normal exit spacing.
5. Run `npm test` and `npm run qa:components`.

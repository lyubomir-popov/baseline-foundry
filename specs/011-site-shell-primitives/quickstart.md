# Quickstart: Site shell primitives

Run `npm test` and `npm run qa:components`. Review the application-layout,
basic-section, table and figure demos at 390, 1035, 1036 and 1280px in light
and dark themes. Confirm pinned footers do not move when panel content scrolls,
paired panel footers share their block-end edge, linked titles expose hover and
focus states, RTL start alignment flips, and no horizontal page overflow is
introduced.

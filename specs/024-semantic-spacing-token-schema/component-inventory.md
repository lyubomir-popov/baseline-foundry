  manifest, used only to carry stable part identities and detect source drift

The inventory unit is an exported React render part plus each already-known
internal or compound render part that owns or bounds spacing. Hooks, contexts,
tests, stories, documentation chrome and application fixtures are excluded
unless an existing row already records a spacing boundary. Non-React rows are
limited to direct shared spacing/density/control-seat consumers and the named
FR-036 forks.

`compositionClue` is inherited audit vocabulary, not a token assignment. The
`styles` array is a source pointer found beside or imported by the render
module, not a claim that every declaration in that stylesheet belongs to the
row. T006 replaces every former `t006Disposition: null` with resolved
per-axis/per-edge candidate assignments, explicit boundaries and any
part-specific exception. T007 remains the exhaustive declaration sweep.

## T006 candidate assignments

The JSON is now schema version 2. Its `boundary.candidateRoles` list contains
the eleven candidates carried into CP1 after the T009 inline-peer breaker:

| Axis | Relationship | Candidate roles |
|---|---|---|
| Inline | inset | `field`, `action`, `continuation`, `surface` |
| Inline | gap | `mark`, `element` |
| Block | inset | `control`, `surface` |
| Block | gap | `element`, `group`, `pattern` |

Each row's `t006Disposition` expands its profile into exact `axis`, `edge` and
`role` records. A condition limits variant-only relationships such as a
mark-to-copy gap. Boundaries state why an unassigned edge, axis or whole part
does not create a component semantic role. The source of these profiles and
the exact 169-ID coverage assertion is
[`scripts/t006-dispositions.ts`](scripts/t006-dispositions.ts); regeneration
fails on a missing, duplicate or stale ID, an unconditional double assignment
to one edge, or an assignment that overlaps an explicit boundary.

Ten candidates have direct membership in this frozen component denominator.
`spacing.gap.pattern.block` has no component-row member: its retained candidate
is the page-section step already established by FR-043, while FR-021 keeps
page/grid owners outside this component denominator. CP1 must either retain
that external ownership explicitly or remove it from the component count; T006
does not fabricate a component member to make the count look closed.

`spacing.gap.element.inline` is the T009 correction for separation between peer
items or controls (Card/Modal/SidePanel footer items, Range slider/number, and
choice columns). It is distinct from `spacing.gap.mark.inline`, whose breaker is a
marker/icon/caret and its copy. T009 also corrects Choices rows to
`element.block` and SideNavigation section separation to `group.block`; neither
change is value-driven.

`SideNavigation.NavTree` renders `display: contents` and therefore delegates
all visible spacing to its child rows; it is boundary-only. Composite profiles
for Button, Accordion Item, Choices, ColorInput, TokenTable,
SideNavigation.ItemExpandable, Combobox List and Popover condition or separate
their variant or sub-box relationships so one row never claims two
unconditional roles on the same edge.

The ColorInput row records the required exception: its popover separator row
has a block-start border and no block-end border while inheriting symmetric
host padding. The recut must read and subtract the actual border on each edge;
it must not reuse a nominal symmetric host-border value.

These are proposed memberships, not approved tokens. T008 supplies the
proportionate current rendering, T009 records merge attempts and breakers, and
T012 is the independent CP1 adversarial review.

## Current-main reconciliation

All 142 production source paths in the prior inventory still exist. Their
current Git blob IDs and SHA-256 hashes are frozen in the JSON. After canonical
newline comparison with the manifest-verified Spec 022 files, 99 render sources
are unchanged and 43 changed.

The stylesheet reconciliation is deliberately source-level, not a claim of
semantic completion:

- 94 previously recorded production/evidence stylesheets changed;
- 15 current-main stylesheets are new;
- nine of the new files belong to Modal or the new SideNavigation parts;
- four belong to SidePanel;
- two belong to the unexported `DensityTestbed` Storybook spike and are
  explicitly excluded;
- two removed files were Storybook evidence chrome, not production owners.

This amount of drift means the old rendered ledger remains historical evidence
for the taxonomy argument, but cannot certify current-main geometry. T006 must
classify the frozen parts from current source; T008 supplies proportionate
current rendering after assignments exist.

## Reproduction

Archive the exact source commit without creating a worktree, then run:

```powershell
npx tsx specs/024-semantic-spacing-token-schema/scripts/build-component-inventory.ts `
  --pragma-snapshot <archive-root> `
  --pragma-repo <pragma-repository> `
  --legacy-inventory <spec-022-reference>/config/react-spacing-inventory.ts `
  --legacy-source-manifest <spec-022-audit>/evidence/source-manifest.json `
  --source-ref main `
  --upstream-ref origin/main `
  --output specs/024-semantic-spacing-token-schema/component-inventory.json
```

The output is deterministic for the same source commit and legacy inputs. It
fails if local `main` is not equal to `origin/main`, or if a denominator source
or Git blob cannot be resolved. Recorded source hashes are computed from raw Git
blob bytes. Every consumed snapshot file is compared with that blob after only
CRLF/CR newline normalization, so checkout line-ending policy cannot change the
authority or conceal stale snapshot content.

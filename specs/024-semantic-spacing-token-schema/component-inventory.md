# Current-main component denominator

This is the T005/T005a/T005b freeze of the component denominator. The
machine-readable authority is [`component-inventory.json`](component-inventory.json),
generated by [`scripts/build-component-inventory.ts`](scripts/build-component-inventory.ts).

## Source identity

- Repository: `canonical/pragma`
- Ref fetched: `origin/main`
- Commit: `3706f5ea3b45af0fe43c2308a0e39d81a4cd99a2`
- Commit date: 2026-09-28
- Prior audit input: the 2026-09-21 Spec 022 React inventory and source
  manifest, used only to carry stable part identities and detect source drift
- Semantic assignments: intentionally `null`; T006 owns them

The inventory unit is an exported React render part plus each already-known
internal or compound render part that owns or bounds spacing. Hooks, contexts,
tests, stories, documentation chrome and application fixtures are excluded
unless an existing row already records a spacing boundary. Non-React rows are
limited to direct shared spacing/density/control-seat consumers and the named
FR-036 forks.

`compositionClue` is inherited audit vocabulary, not a token assignment. The
`styles` array is a source pointer found beside or imported by the render
module, not a claim that every declaration in that stylesheet belongs to the
row. T006 must replace every `t006Disposition: null` with a role assignment or
explicit boundary; T007 remains the exhaustive declaration sweep.

## Current-main reconciliation

All 142 production source paths in the prior inventory still exist. Their
current Git blob IDs and SHA-256 hashes are frozen in the JSON. Of those render
sources, 98 are byte-identical to the captured Spec 022 source and 44 changed.

The stylesheet reconciliation is deliberately source-level, not a claim of
semantic completion:

- 94 previously recorded production/evidence stylesheets changed;
- 11 current-main stylesheets are new;
- nine of the new files belong to Modal or the new SideNavigation parts;
- two belong to the unexported `DensityTestbed` Storybook spike and are
  explicitly excluded;
- two removed files were Storybook evidence chrome, not production owners.

This amount of drift means the old rendered ledger remains historical evidence
for the taxonomy argument, but cannot certify current-main geometry. T006 must
classify the frozen parts from current source; T008 supplies proportionate
current rendering after assignments exist.

## Reproduction

Archive the exact source commit without creating a worktree, then run:

```powershell
npx tsx specs/024-semantic-spacing-token-schema/scripts/build-component-inventory.ts `
  --pragma-snapshot <archive-root> `
  --pragma-repo <pragma-repository> `
  --legacy-inventory <spec-022-reference>/config/react-spacing-inventory.ts `
  --legacy-source-manifest <spec-022-audit>/evidence/source-manifest.json `
  --source-ref origin/main `
  --output specs/024-semantic-spacing-token-schema/component-inventory.json
```

The output is deterministic for the same source commit and legacy inputs. It
fails if a denominator source or Git blob cannot be resolved.

3. BF button states on one composed shadow list

These same paint owners are used for normal and forced-colours evidence. Focus, invalid, selection, four sides, uniform stroke, and elevation have separate named slots. Every empty slot is a transparent shadow.

4. Forced-colours ownership on the same controls

Forced-colours capture drives the section 3 controls directly; it does not render a duplicate state set. Each state owns an inset boundary outline. Static focus replaces it with a thicker inset outline, while glyph, underline, and dashed cues preserve state without colour.

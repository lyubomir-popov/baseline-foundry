Layout border versus paint-only stroke

BF fidelity recut · review pending

FR-063 — strokes take no layout space. The proposed construction removes the CSS layout border and paints the same boundary inside the box with an inset box-shadow. In forced colours, an inset outline paints the boundary instead.

What this page does and does not prove

It proves the candidate construction on real BF geometry and shows BF's already-shipped fully rounded chip precedent. It does not claim Pragma integration, invent combined button states, or redraw native range chrome. Mixed per-side strokes and rounded-corner taper remain a CSS-mechanism test in the specification, not a BF button variant.

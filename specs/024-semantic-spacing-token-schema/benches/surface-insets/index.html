Why Docs/App still need 4px or 8px

Docs/App use a 12px action inset. Literal “half” is 6px, which sits between 4px grid lines. Changing the border construction cannot make 6px a multiple of 4px, so the design value must resolve to the nearer 4px or 8px step.

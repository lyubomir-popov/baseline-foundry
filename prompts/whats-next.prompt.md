# What's next?

Read `AGENTS.md`, `AGENT-INBOX.md`, `docs/agent-index.md`, `docs/specs.md`, and
`TODO.md`. Read `INBOX.md` and triage any user note into a numbered spec or the
short backlog. If a spec is active, open only that package.

Verify branch/package alignment, dirty-work preservation boundaries, current
claims against source, and the smallest relevant test. Use the active spec's
task order first; use `TODO.md` only for cross-spec priority.

Report the source-of-truth summary, inbox triage, concrete drift, build quality,
one recommended next task, first steps, and real blockers. Do not implement
unless the user asked you to proceed.

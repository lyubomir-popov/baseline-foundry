Column span rule

The visual rule is simple: spans can only bisect. Valid spans are 8, 4, 2, and 1 on the 8-column grid, then 16, 8, 4, 2, and 1 on the 16-column grid. Thirds are explicitly outside the system.

8-column grid

Span 8Full row
Span 4Half row
Span 2Quarter row
Span 1Utility cell
InvalidThirds are not allowed

16-column grid

Span 16Full row
Span 8Half row
Span 4Quarter row
Span 2Eighth row
Span 1Sixteenth row

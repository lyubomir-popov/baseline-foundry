App Tier Examples

Standalone examples using the application-tier model from the grid spec (v0.2) and spacing spec (v0.4), with the docs-typescale app-tier font settings (Ubuntu Sans).

Typography
Ubuntu Sans · body 0.875rem/1.25rem · headings per docs-typescale/config/typography-config-apps.json
Spacing model
Container-owned (spacing spec §2.4) · zero nudges (§2.6.3) · gap-based vertical rhythm
Grid
Container-based · 4/8/16 columns · power-of-2 spans · 1.5rem app gutters at large (grid spec §2.3)
Layout pattern
8-col grid · heading span-2 (left) · form span-4 (middle) · 2 cols empty (right)

Pages

  • Settings page — MAAS network, commissioning, DNS, NTP, proxy settings
  • Machine configuration — Add machine form with two-column inner fields
  • Subnets — List table, status indicators, subnet detail form
  • Machines — Dashboard cards with nested density, machine list table
  • Users — User table, add user form, notification banners

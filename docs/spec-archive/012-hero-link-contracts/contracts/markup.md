# Markup contract

## Quiet linked title

```html
<h2><a class="bf-basic-section-title-link" href="…">Section title</a></h2>
```

## Default hero

```html
<section class="bf-hero" aria-labelledby="hero-title">…</section>
```

The block-start divider is part of the hero pattern; do not insert a loose rule before it.

## Divider opt-out

```html
<section class="bf-hero is-borderless" aria-labelledby="hero-title">…</section>
```

`is-borderless` removes only the entry divider.

## Summary

Make repository state deterministic, retire only proven merged residue, complete
the historical in-app-browser evidence, extract cohesive owners from the three
largest mixed-responsibility files, and turn the existing npm OIDC publication
into a guarded end-to-end release. Declare the supported Node/npm contract,
evaluate current stable TypeScript and Vite majors, and release the resulting
maintenance version without changing BF's generated design contracts.

## Technical Context

**Language/Version**: TypeScript 7 generating CSS/JSON and browser/library JavaScript; Node.js 22.14+ and 24; npm 11.19

**Primary Dependencies**: `@lyubomir-popov/baseline-nudge-generator` 1.5.1, Playwright, Vite 8, GitHub Actions, npm trusted publishing

**Storage**: Generated filesystem artifacts, Git refs/worktrees, npm registry package, GitHub release assets

**Testing**: strict TypeScript checking, generated-contract assertions, Playwright behavior/baseline/screenshot suites, package dry-run inspection, empty-directory registry smoke test, Git ancestry and semantic-diff guards

**Target Platform**: Windows contributor checkout; GitHub-hosted Windows CI and Ubuntu release runner; modern browsers; Node 22/24 downstream build consumers

**Project Type**: Generated CSS/JSON design-system library with browser demos and a public npm package

**Performance Goals**: No runtime or CSS growth from refactoring; release checks remain within the existing 30-minute workflow budget

**Constraints**: Preserve generated bytes before dependency upgrades, public exports and selector order; never hand-edit `dist/`; never delete unmerged or semantically dirty state; no stored npm write token; registry versions are immutable

**Scale/Scope**: Three hotspot owners, 13 archived packages, 27 local branches, 19 non-main remote refs at discovery, four built-in tiers, 30 root exports and 15 CSS/token/surface entry points

- **Small, earned primitives**: Pass. No public primitive or compatibility alias is introduced.
- **Accessible, intrinsic composition**: Pass. The in-app review verifies existing focus, overflow, responsive and directional behavior without changing markup contracts.
- **Generated contracts and public evidence**: Pass. Source modules remain authoritative; generated hashes, static assertions, browser evidence and package smoke checks are explicit gates.
- **Lean specification-owned state**: Pass. Spec 014 is the only active package and owns every audit finding, task and closeout record.

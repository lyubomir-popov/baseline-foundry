# Product Roadmap

## Stage 1

Lean baseline engine:

- IBM Plex metric source
- editorial typescale
- prose spacing
- baseline overlay

## Stage 2

Layout foundation:

- section and strip rhythm
- stack and cluster primitives
- container-query grid
- fixed-width/page primitives

## Stage 3

Consumer hardening:

- clearer token semantics
- stronger validation
- canonical documentation for authors

## Stage 4

Optional extensions only if they are justified:

- a second preset or theme line
- React primitives for the layout/typography foundation
- additional composed patterns built from the core primitives

## Explicit non-goal

Do not turn this repo into a broad compatibility rewrite by accident.

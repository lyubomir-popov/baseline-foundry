Editorial and documentation keep element-owned flow.

Paragraphs, headings, lists, and rules carry their own vertical spacing. That keeps prose composable because parents do not need to know which element comes next in order to space it correctly.

Switch to the app tier and the same chapter becomes the zero-nudge line: semantic after-space is removed and the container is expected to own the gaps between rows, cards, and shell regions.

The spacing change is structural, not cosmetic. Editorial tiers align text blocks to the baseline. App tiers keep the same token system but transfer ownership of most vertical separation to layout containers.

Body-line rhythm

Spec 026. Flow text anywhere in a .bf-theme – paragraphs, headings, heading groups and prose lists – takes a phase inset after its measured nudge and closes to whole body lines by default, so adjacent text blocks need no container gap. Component internals keep the baseline-unit ledger, and adding is-baseline-rhythm to a .bf-theme root restores it for the whole subtree. Each comparison shows the default beside the opt-out for the active tier; the ruling marks every body line.

Container gaps – ruled (c)

Text blocks space themselves: the closure already supplies one blank body line, so prose and pattern-internal stacks cancel their gap between two adjacent text blocks. Section stacks keep their gap. Text next to a component keeps the gap, so text after a component starts on the baseline-unit grid and its body-line phase is not guaranteed.

Lists

The list owns one block start and one closure. Tight items, nested items at every level and the next outer item each advance by one body line; loose items are one body line apart and share the tight text position and dot. A default theme nested inside the opt-out keeps the body-line list.

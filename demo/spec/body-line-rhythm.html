Body-line rhythm

Spec 026. Prose-flow paragraphs and headings take a phase inset after their measured nudge and close to whole body lines by default; prose lists own one block start and one closure, so every item advances by one body line. Adding is-baseline-rhythm to a .bf-theme root restores the baseline-unit ledger. Each comparison shows the default beside the opt-out for the active tier; the ruling marks every body line.

The list owns one block start and one closure. Tight items, nested items at every level and the next outer item each advance by one body line; loose items are one body line apart and share the tight text position and dot. A default theme nested inside the opt-out keeps the body-line list.

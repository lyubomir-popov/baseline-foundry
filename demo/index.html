Baseline Foundry

A lean baseline-aligned system for prose rhythm and grid composition.

This repo keeps the metric-driven baseline model but narrows the surface to typography, editorial flow, section rhythm, and a responsive grid, now using IBM Plex Sans as the editorial metric source for this confirmation pass.

Editorial spacing

The default flow is element-owned.

Paragraphs, headings, lists, and quotes carry their own vertical spacing so content remains substitutable. Parents do not need to know what comes next in order to space it correctly.

That makes this repo a better home for prose, documentation, and future portfolio content than the broader compatibility package it was forked from.

Baseline alignment stays immutable. Everything else has to earn its place as a durable primitive.

What ships right now

  • IBM Plex metric-driven typescale
  • Editorial prose defaults
  • Section and strip rhythm
  • Stack, cluster, page, measure, and grid primitives

Grid primitives

The grid is container-aware and deliberately strict.

Instead of shipping named shell objects, the system provides a responsive grid that scales from 4 to 8 to 16 columns as the container grows. Spans follow power-of-2 divisions so layouts stay aligned and resist arbitrary drift.

Span 4

Quarter-width module on the largest grid, half-width on the medium grid.

Span 8

Half-width primary module that still becomes full-width when the container narrows.

Span 4

Companion block that lands cleanly on the same keyline system.

Span 2

Smaller metadata or utility module for wide containers.

Span 2

Pairs cleanly with another narrow block instead of creating thirds.

Span 4

Power-of-2 spans keep nested and adjacent layouts more predictable.

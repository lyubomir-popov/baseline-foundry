Container-owned spacing

The layout becomes an intentional two-column documentation composition when its own available width supports it. On narrow surfaces, the side navigation retains its drawer ownership while the article returns to the full available measure.

Readable at every width

The article column has no forced span helper and does not need a runtime layout wrapper. The composition uses the same public side-navigation primitive as a standalone documentation drawer.

No empty mobile rail

Below the composition threshold, navigation and content occupy the same single column. If an author omits the navigation slot entirely, the content remains full width.
